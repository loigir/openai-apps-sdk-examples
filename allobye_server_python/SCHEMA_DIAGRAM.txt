┌─────────────────────────────────────────────────────────────┐
│                     KEY RELATIONSHIPS                       │
└─────────────────────────────────────────────────────────────┘

1. SCHOOLS → CHILDREN
   One school has many children

2. CHILDREN ←→ DELEGATES (via delegate_children)
   Many-to-many authorization relationship

3. DELEGATES → PICKUPS
   One delegate can have many pickups

4. PICKUPS ←→ CHILDREN (via pickup_children)
   One pickup can involve multiple children
   One child can have multiple pickups

5. CHILDREN → EMERGENCIES
   One child can have many emergencies


┌─────────────────────────────────────────────────────────────┐
│                      INDEXES                                │
└─────────────────────────────────────────────────────────────┘

SCHOOLS:
  • idx_schools_name ON name

CHILDREN:
  • idx_children_school_id ON school_id
  • idx_children_parent_email ON parent_email

DELEGATES:
  • idx_delegates_email ON email
  • idx_delegates_is_active ON is_active

PICKUPS:
  • idx_pickups_scheduled_time ON scheduled_time
  • idx_pickups_status ON status
  • idx_pickups_pickup_person_id ON pickup_person_id
  • idx_pickups_status_scheduled_time ON (status, scheduled_time)

PICKUP_CHILDREN:
  • idx_pickup_children_child_id ON child_id
  • idx_pickup_children_checked_out ON checked_out

DELEGATE_CHILDREN:
  • idx_delegate_children_child_id ON child_id
  • idx_delegate_children_is_active ON is_active

EMERGENCIES:
  • idx_emergencies_child_id ON child_id
  • idx_emergencies_created_at ON created_at
  • idx_emergencies_resolved ON resolved
  • idx_emergencies_type_resolved ON (emergency_type, resolved)


┌─────────────────────────────────────────────────────────────┐
│                        TRIGGERS                             │
└─────────────────────────────────────────────────────────────┘

1. AUTO-UPDATE updated_at
   ├─ update_schools_updated_at
   ├─ update_children_updated_at
   ├─ update_delegates_updated_at
   ├─ update_pickups_updated_at
   └─ update_emergencies_updated_at

2. EMERGENCY NOTIFICATION
   └─ emergency_notification
      Sends pg_notify when emergency created

3. PICKUP STATUS CASCADE
   └─ pickup_status_cascade
      Auto-updates children when pickup status changes:
      • cancelled → uncheck all children
      • completed → check out unchecked children
